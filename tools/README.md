# Tools

Shared source used to build the projects.

- `gen_launchers.py` writes each project's .bat launchers, run.sh and README.md from a spec in `reports/build/specs/`.
- `demo_a.py` is the original of each backup project's `demo.py` (synthetic records and safe ransomware simulations).
- `geo_b.py` is the original of each conflict project's `geo.py` (geography helpers and synthetic incident history).

Each project folder carries its own copy, so it runs alone on its own computer.
